# Event Pulling API

Eerste concept-versie van de ORI API waarin de [Aanlever ORI API van Logius KOOP](https://gitlab.com/koop/woo/aanleveren-ori) is omgezet naar een event-pulling interactiepatroon zodat de afnemer altijd kan synchroniseren op basis van de verschillen in de vorm van CRUD-events, zie [Redoc](https://redocly.github.io/redoc/?url=https://raw.githubusercontent.com/VNG-Realisatie/ODS-Open-Raadsinformatie/refs/heads/master/docs/event%20polling/versie%200.0.1/openapi.yaml).
